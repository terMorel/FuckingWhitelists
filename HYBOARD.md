# Fucking Whitelists Control

Отдельная панель для уже работающего нативного Hysteria2. Она создаёт персональные доступы через существующую утилиту `hy-access` и **не участвует в передаче VPN-трафика**.

## Что умеет

- показывает состояние Hysteria и наличие UDP/443;
- создаёт отдельный ключ для каждого человека или устройства;
- показывает и скачивает персональный QR, копирует URI;
- ротирует ключ и немедленно отзывает старый;
- отзывает доступ;
- задаёт срок действия с автоматическим отзывом;
- ведёт локальный журнал административных действий;
- работает на телефоне и компьютере.

## Почему панель не снижает скорость

```text
Клиент ── Hysteria2 / UDP 443 ──> нативный hysteria-server ──> Интернет

Браузер ── SSH-туннель ──> FW Control ── Unix socket ──> root broker ──> hy-access
```

Панель отсутствует в первой строке. После проверки токена Hysteria передаёт трафик самостоятельно. Остановка панели не роняет уже выданные ключи и не меняет UDP/443.

## Безопасность

- интерфейс по умолчанию слушает только `127.0.0.1:28474` и открывается через SSH-туннель;
- пароль хранится только как Argon2-хеш;
- сессия подписана, изменения защищены CSRF-токеном;
- есть ограничение попыток входа;
- веб-процесс работает без root;
- веб-процесс работает с `NoNewPrivileges=1` и не использует `sudo`;
- отдельный root-broker не имеет сетевого порта и доступен только через Unix-сокет `root:hyboard 0660`;
- root-broker принимает только `list`, `status`, `add`, `show`, `rotate`, `revoke` и строго проверяет имя;
- WireGuard, Xray, сетевые правила и конфигурация Hysteria недоступны панели;
- реальные IP, токены, QR и пароли не входят в репозиторий.

## Локальная демонстрация

Требуется Python 3.10+.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e '.[test]'
HYBOARD_DEMO=1 hyboard
```

Откройте `http://127.0.0.1:28474`, пароль `demo`. Демо использует только данные в памяти и не подключается к VPN.

## Установка на сервер

Установщик рассчитан на существующую схему с `/usr/local/sbin/hy-access`, `/etc/hysteria/users.json` и `/root/hysteria-access`.

```bash
git clone https://github.com/terMorel/FuckingWhitelists.git
cd FuckingWhitelists
sudo bash deploy/install.sh
```

Установщик не перезапускает и не меняет Hysteria, Xray или WireGuard. Он создаёт отдельного системного пользователя, панель и минутный таймер сроков доступа.

С компьютера откройте защищённый туннель:

```bash
ssh -L 28474:127.0.0.1:28474 root@SERVER_IP
```

После этого панель доступна по адресу `http://127.0.0.1:28474`.

Смена пароля администратора без передачи пароля в аргументах процесса:

```bash
sudo /opt/hyboard/.venv/bin/python /opt/hyboard/deploy/set-password.py
sudo systemctl restart hyboard.service
```
