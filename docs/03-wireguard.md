# 3. WireGuard простыми словами

[← Маршрут трафика](02-traffic-flow.md) · [Оглавление](../README.md) · [TURN и WebRTC →](04-turn-webrtc.md)

## Что это такое

WireGuard — VPN-протокол. Он создаёт защищённый виртуальный сетевой кабель между телефоном и сервером.

Через этот «кабель» могут идти пакеты браузера, мессенджера и других приложений. WireGuard:

- шифрует данные;
- проверяет, что подключается разрешённое устройство;
- создаёт виртуальный IP-адрес телефона;
- передаёт почти любой обычный IP-трафик.

## Ключи вместо паролей

У каждой стороны есть пара ключей:

```text
приватный ключ — хранится в секрете;
публичный ключ — можно передать другой стороне.
```

Сервер разрешает подключение только тем клиентам, чьи публичные ключи внесены в его конфигурацию.

Приватный ключ нельзя публиковать, присылать в чат или использовать сразу на нескольких телефонах.

## Почему обычный WireGuard здесь не подходит

При прямой работе:

```text
WireGuard телефона → публичный IP VPS
```

Оператор видит адрес VPS и характерный UDP-трафик. При строгом белом списке соединение с запрещённым IP блокируется.

В нашей схеме WireGuard отправляет пакеты локально:

```text
Endpoint = 127.0.0.1:9000
```

Дальше их несёт FreeTurn через VK. То есть WireGuard отвечает за защищённый IP-туннель, а FreeTurn — за доступный маршрут доставки.

## Что такое handshake

Handshake — короткое криптографическое рукопожатие. Оно подтверждает, что клиент и сервер знают правильные ключи и могут начать обмен.

На VPS команда `wg show` обычно показывает:

```text
latest handshake: ... seconds ago
transfer: ... received, ... sent
```

Если handshake отсутствует, WireGuard-пакеты не достигли сервера либо ключи/адреса настроены неверно.

## Что такое MTU

MTU — максимальный размер одного сетевого пакета без дополнительного дробления.

В нашей схеме несколько оболочек вложены друг в друга. Слишком большой пакет может раздробиться или потеряться. Тогда маленькие страницы ещё открываются, а тяжёлые сайты зависают.

Практический смысл:

- `1280` — частая начальная величина;
- `1120` — возможный диагностический вариант при проблемах с тяжёлыми сайтами;
- слишком маленький MTU увеличивает накладные расходы и не создаёт скорость из ничего.

## Чего WireGuard не делает

WireGuard не:

- делает VK TURN быстрее;
- решает CAPTCHA;
- гарантирует прохождение белого списка;
- скрывает факт соединения телефона с VK;
- исправляет потери внешнего медиаканала.
